# Googleパスワードマネージャ

#### 情報更新日
  2026/03/31

## 1.認証器名または準拠標準
  Googleパスワードマネージャ

## 2.認証器詳細

- ### 認証器説明
  Googleパスワードマネージャは、学認に参加したサービスを利用する際に、各サービス固有のパスワードやパスキーを用いた認証を行うために使用できる認証支援ツールである。提供形態は、Android端末やアプリ、Google Chromeブラウザに組み込まれた機能としてGoogle社から提供される。
  パスキープロバイダ機能は、Googleパスワードマネージャが保持する各サービスに対応するパスキーの秘密鍵を用い、利用者が所持するデバイス上で生体認証または知識認証による本人確認を行ったうえで、サービスに対して署名済みチャレンジを送信することで認証を実施する。

- ### 認証器の特徴
  パスワードマネージャは、各サービスごとにランダムかつ高強度なパスワードやパスキーを自動生成・暗号化保存・自動入力するツールであり、パスワードマネージャで管理している認証情報はクラウド経由でデバイス間での同期も図られる。

- ### 認証器種類
  パスワードマネージャとして以下の要素を管理している

    - Memorized Secret（パスワードとして）
    - Multi-Factor Cryptographic Software（パスキープロバイダとして）
