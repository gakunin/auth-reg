# UPKI Digital Certificate Issuing Service, Client Certificate

#### Updated on:

2024/03/29

## 1.Authenticator Name or Compliance Standard

UPKI Client Certificate

## 2.Authenticator Details

### Authenticator Description

- The UPKI client certificate is an authenticator used when accessing services participating in GakuNin, with the client certificate issued by the UPKI Digital Certificate Issuing Service. The UPKI client certificate is categorized as Single-Factor Cryptographic Software. This authenticator is provided when the user obtains the issued client certificate and installs it on their own device.

### Authenticator Features

- Cryptographic Software is a possession-based authenticator based on a digital certificate, which is used by a specific client to prove their identity to a service.

### Authenticator Types

Single-Factor Cryptographic Software

### Official URL

- <https://certs.nii.ac.jp/>

### Providers

SECOM Trust Systems Co., Ltd.

### Authenticator Version

Compliant with the specification change as of 2023-12-14 (Reference URL: <https://certs.nii.ac.jp/news/20231013> )

### Authenticator Category

Single-Factor

### Authentication Factors

Possession-based factors(“something you have”)
