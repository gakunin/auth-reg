# Microsoft Authenticator

#### Updated on:

2024/02/29

## 1.Authenticator Name or Compliance Standard

Microsoft Authenticator

## 2.Authenticator Details

### Authenticator Description

- Microsoft Authenticator is an authenticator that can be used to perform authentication using a One-Time Password (OTP) when accessing services participating in GakuNin. It is an OTP app classified as a Single-Factor OTP device. This authenticator is provided in the form of an app installed on a smartphone, and is made available to users through the iOS and Android app stores by Microsoft.

### Authenticator Features

- An OTP app is an authenticator that generates OTPs that become invalid once used. The user obtains the OTP through a separate channel from the one used to connect to the service. When using an OTP app in GakuNin, the user is required to enter a knowledge-based factor, such as a password, for the first step of authentication, and then enter the OTP generated by the OTP app for the second step of authentication.

Single-Factor OTP device
